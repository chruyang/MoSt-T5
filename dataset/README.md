# 分子数据集说明文档

## 📊 原子映射质量报告

### 映射有效性统计
- **映射有效率**: 97.96%
- **映射失败率**: 2.04%

### 📈 数据质量分析

#### 成功映射的数据 (97.96%)
- 大部分常见有机分子结构
- 标准的单分子化合物
- 具有清晰拓扑结构的分子
- 能够被CAMT5模型正确解析的化合物

#### 映射失败的数据 (2.04%)
主要包括以下类型的复杂结构：

1. **极其复杂的化学结构**
   - 高度支化的聚合物
   - 大环化合物
   - 多核金属配合物
   - 具有复杂立体化学的分子

2. **特殊化学环境**
   - 存在不常见的化学键类型
   - 特殊的电子结构
   - 难以确定的共振结构
   - 极端的官能团组合

### 💡 处理建议

对于映射失败的2.04%数据，您有两种处理方式：

#### 方案一：数据过滤（推荐）
```python
# 在Dataset的__getitem__方法中
if mapping is None:
    return None  # 跳过无效数据
```

#### 方案二：特征降级
```python
# 对于没有有效映射的数据，不使用3D特征
if mapping is None:
    # 使用2D特征或其他替代表示
    use_3d_features = False
```

### 🛠 技术细节

映射生成失败的主要技术原因：
- RDKit无法正确解析某些极端结构
- CAMT5的linearize函数在复杂情况下追踪失败
- 原子索引对齐算法遇到边界情况
- 内存或计算资源限制

### 📋 使用注意事项

1. **训练数据筛选**：建议在训练前过滤掉mapping为None的样本
2. **评估指标**：在报告模型性能时，应注明实际使用的有效数据比例
3. **数据增强**：可以考虑对失败案例进行人工标注或使用其他工具补充

### 🔍 质量保证

- 97.96%的成功率表明数据处理流程整体可靠
- 失败案例主要集中在化学结构的边缘情况
- 对主流分子类型处理效果良好
- 可以满足大多数机器学习应用的需求
